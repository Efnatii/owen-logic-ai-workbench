# AVR 2-in-1 with section breaker for PR200

Папка содержит один ST-функциональный блок для ОВЕН Logic/ПР200 и доказательные тесты его логики.

## Файлы

- `FB_AVR_2IN1_SECTION_PR200.st` - один функциональный блок АВР 2-в-1 с секционированием.
- `avr_2in1_section_sim.py` - Python-модель той же логики для проверки.
- `test_avr_2in1_section.py` - 38 сценарных тестов.
- `test_avr_2in1_section_invariants.py` - 34 теста инвариантов, включая полный перебор входов, состояний автомата и внутренних состояний задержек.
- `TEST_REPORT.txt` - отчет последнего успешного прогона.

## Входы

Все входы подаются уже в смысловой логике после внешних инверсий.

- `xManualSelector`: `TRUE` = ручной режим.
- `xAutoReturn`: `TRUE` = возвращаться к нормальной схеме после восстановления обоих вводов.
- `udiInputDelaySec`: задержка подтверждения смены целевой схемы по вводам. Нужна, чтобы кратковременный провал напряжения не переключал мотор-приводы.
- `udiSectionCloseDelaySec`: отдельная задержка включения `30F` секционного автомата. Нужна, чтобы после включения живого вводного автомата не подключать вторую секцию сразу.
- `xU1Ok`: напряжение ввода 1 в норме.
- `xU2Ok`: напряжение ввода 2 в норме.
- `xQF1On`, `xQF1Off`, `xQF1Fault`: допконтакты и авария `10F`, ввод 1.
- `xQF2On`, `xQF2Off`, `xQF2Fault`: допконтакты и авария `20F`, ввод 2.
- `xQFSOn`, `xQFSOff`, `xQFSFault`: допконтакты и авария `30F`, секционный автомат.

## Выходы на PR200

- `xQ1 -> Q1`: включить `10F`, ввод 1.
- `xQ2 -> Q2`: выключить `10F`, ввод 1.
- `xQ3 -> Q3`: включить `20F`, ввод 2.
- `xQ4 -> Q4`: выключить `20F`, ввод 2.
- `xQ5 -> Q5`: включить `30F`, секционный автомат.
- `xQ6 -> Q6`: выключить `30F`, секционный автомат.

## Схемы

- `udiTargetScheme = 10`: нормальная схема, `10F` включен, `20F` включен, `30F` выключен.
- `udiTargetScheme = 11`: ввод 1 питает обе секции, `10F` включен, `20F` выключен, `30F` включен.
- `udiTargetScheme = 12`: ввод 2 питает обе секции, `10F` выключен, `20F` включен, `30F` включен.
- `udiTargetScheme = 0`: нет доступного ввода, все выключить.

## Задержки

В ST нет `TON`, `TIME` и внешнего импульсного входа: задержки считаются внутренними `UDINT`-счетчиками циклов вызова блока. Если блок вызывается один раз в секунду, значения параметров равны секундам.

- `udiInputDelaySec = 0`: смена целевой схемы по вводам принимается сразу.
- `udiSectionCloseDelaySec = 0`: `30F` включается сразу после выполнения безопасных условий.
- `udiInputDelaySec` не задерживает `30F`, если `udiSectionCloseDelaySec = 0`.
- `udiSectionCloseDelaySec` не задерживает выбор целевой схемы по вводам.

Секционный `30F` может получить команду `Q5` только после подтверждения: здоровый вводной автомат включен, противоположный вводной автомат выключен, затем выдержана отдельная задержка `udiSectionCloseDelaySec`. Пока `xSectionCloseDelayActive = TRUE`, команда `Q5` запрещена.

Для восстановления после полного обесточивания добавлено правило темного старта: если `30F` остался включенным механически, а живой вводной автомат выключен, блок сначала отключает `30F`, потом включает живой вводной автомат, потом выдерживает `udiSectionCloseDelaySec` и включает `30F`. Поэтому один ввод не получает бросок нагрузки сразу двух секций.

## Безопасность

- Запрещенная параллель: `10F`, `20F` и `30F` одновременно включены. В этом состоянии включающие команды запрещены, разрешены только команды отключения уже включенных аппаратов.
- `10F` или `20F` нельзя включить, пока `30F` не подтвержден выключенным.
- `On = TRUE` и `Off = TRUE` всегда аварийная неопределенность.
- `On = FALSE` и `Off = FALSE` допустимо только для аппарата, которому сейчас дана команда.
- Авария любого аппарата переводит АВР в ручной/аварийный режим.
- Аварийный режим снимается автоматически, когда аварийные условия ушли.

## Запуск тестов

```powershell
cd C:\__SELF_PC__\AVR_2IN1_SECTION_PR200
python -m unittest -v test_avr_2in1_section.py test_avr_2in1_section_invariants.py
```

Последний прогон: 72 теста, все успешно. В инвариантных тестах перебираются 8192 комбинации входов на каждое состояние автомата, плюс отдельный полный перебор внутренних состояний задержки входов и задержки включения `30F`.
