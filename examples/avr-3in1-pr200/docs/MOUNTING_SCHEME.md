# Монтажная схема АВР 3-в-1

Это упрощенная монтажная схема: один блок АВР и номера цепей. Внутренняя логика не показана.

## Входные цепи

| Цепь | Сигнал блока | Назначение |
|---:|---|---|
| `101` | `xManualSelector` | Переключатель авто/ручной. `1 = ручной` |
| `102` | `xAutoReturn` | Разрешение автовозврата на ввод 1 |
| `111` | `xU1Ok` | Ввод 1: напряжение в норме |
| `112` | `xU2Ok` | Ввод 2: напряжение в норме |
| `113` | `xU3Ok` | Ввод 3: напряжение в норме |
| `121` | `xQF1On` | `40F` включен |
| `122` | `xQF1Off` | `40F` выключен |
| `123` | `xQF1Fault` | `40F` авария |
| `131` | `xQF2On` | `50F` включен |
| `132` | `xQF2Off` | `50F` выключен |
| `133` | `xQF2Fault` | `50F` авария |
| `141` | `xQF3On` | `60F` включен |
| `142` | `xQF3Off` | `60F` выключен |
| `143` | `xQF3Fault` | `60F` авария |

## Выходные цепи

| Цепь | Выход блока | Физический выход ПР200 | Назначение |
|---:|---|---|---|
| `201` | `xQ1` | `Q1` | Включить `40F` |
| `202` | `xQ2` | `Q2` | Выключить `40F` |
| `203` | `xQ3` | `Q3` | Включить `50F` |
| `204` | `xQ4` | `Q4` | Выключить `50F` |
| `205` | `xQ5` | `Q5` | Включить `60F` |
| `206` | `xQ6` | `Q6` | Выключить `60F` |

## Диагностические сигналы

Эти цепи не обязательно выводить физически. Их удобно вывести на экран/индикацию/в журнал.

| Цепь | Сигнал | Назначение |
|---:|---|---|
| `301` | `xAutoMode` | АВР в автоматическом режиме |
| `302` | `xManualMode` | АВР в ручном/аварийном режиме |
| `303` | `xAlarm` | Общая авария АВР |
| `304` | `xAlarmFault` | Авария `40F/50F/60F` |
| `305` | `xAlarmParallel` | Одновременно включено больше одного ввода |
| `306` | `xAlarmUndefined` | Неопределенное состояние допконтактов |
| `307` | `xNoSource` | Нет доступного ввода |
